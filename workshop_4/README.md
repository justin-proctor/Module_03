## Workshop 4: Metagenome function
This workshop focuses on metagenome assembly of Black Band Disease

This folder contains the complete workflow used to analyze the Black Band Disease (BBD) metagenome throughout 
Workshop 4 of the Marine Genomics module. Included are the shell scripts used to execute each stage of the 
bioinformatics pipeline on the HPC cluster, along with Quarto (.qmd) source files and their corresponding rendered 
HTML reports documenting each analysis step. The workflow includes metagenome assembly with Flye, genome binning 
with MetaBAT2, quality assessment using CheckM, taxonomic classification with GTDB-Tk, genome annotation using 
Prokka, and metabolic pathway inference with MinPath. Together, these files provide a fully reproducible record 
of the analysis, from raw sequencing reads through genome reconstruction, taxonomic identification, and functional 
characterization of the BBD microbial community.
